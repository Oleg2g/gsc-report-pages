Privacy Policy

Last updated: October 14, 2026

About the application

Search Console Telegram Report is a personal, non-commercial application used by its owner to monitor Google Search Console performance.

Data accessed

The application requests read-only access to Google Search Console data, including website impressions, clicks, and search queries.

How data is used

Data is used solely to generate performance reports delivered to the owner's private Telegram chat.

Data sharing

Report contents are transmitted through the Telegram Bot API for delivery to the owner. Data is not sold or used for advertising.

Data storage

OAuth credentials are stored securely for automated access. The application does not maintain a public database of Search Console reports.

Access revocation

The owner can revoke the application's access through Google Account security settings.
